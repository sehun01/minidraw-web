# MiniDraw

REA로 관찰한 사각형 편집 동작을 바탕으로 독립 구현한 로컬 웹 앱입니다. HTML, CSS, 순수 JavaScript와 브라우저의 SVG·Canvas API를 사용했습니다. Excalidraw 원본 코드, 패키지, 글꼴, 아이콘을 사용하지 않았습니다.

## 실행 방법

1. `MiniDraw` 폴더의 네 파일 `index.html`, `styles.css`, `scene.js`, `app.js`를 같은 위치에 둡니다.
2. `index.html`을 Edge 또는 Chrome으로 엽니다. 파일을 우클릭하고 **연결 프로그램 → Microsoft Edge / Google Chrome**을 선택해도 됩니다.
3. 상단 사각형 도구 또는 **R**을 누르고 빈 캔버스를 드래그합니다.

Node.js, npm 설치, 빌드, 로그인, 인터넷 연결이 필요하지 않습니다. 작업 내용은 자동 저장하지 않으므로 종료 전에 **파일 메뉴 → 파일 저장**으로 보관하세요.

## 사용 방법

| 작업 | 방법 |
|---|---|
| 사각형 생성 | 사각형 도구를 선택하고 드래그합니다. 놓으면 생성된 도형이 선택됩니다. |
| 선택 | 선택 도구에서 도형을 클릭합니다. 투명한 도형은 테두리를 클릭합니다. |
| 이동 | 선택 도구에서 도형을 드래그합니다. 크기는 유지됩니다. |
| 크기 조절 | 네 모서리 중 하나의 핸들을 드래그합니다. 반대 모서리를 기준으로 조절합니다. |
| 선택 해제 | 빈 곳을 클릭하거나 Esc를 누릅니다. |
| 스타일 변경 | 왼쪽 패널에서 선 색상·배경색·선 굵기·선 모양·모서리·불투명도를 변경합니다. |
| 삭제 | 도형을 선택하고 Delete 또는 왼쪽 삭제 버튼을 누릅니다. |
| 실행 취소 / 다시 실행 | 왼쪽 아래 화살표 버튼 또는 Ctrl+Z / Ctrl+Shift+Z를 사용합니다. |
| 화면 이동 | 손 도구(H)를 선택하고 캔버스를 드래그합니다. |
| 확대 / 축소 | 왼쪽 아래 + / − 버튼을 누릅니다. 배율 숫자를 누르면 전체 도형을 화면에 맞춥니다. |
| 파일 저장 / 열기 | 왼쪽 위 ☰ 메뉴 또는 Ctrl+S / Ctrl+O를 사용합니다. |
| PNG 내보내기 | 오른쪽 위 내보내기에서 배경 포함 여부와 1×·2×·3× 배율을 선택합니다. |

Mac에서는 Ctrl 대신 Command를 사용할 수 있습니다. 도형 생성·이동·크기 조절 중 Esc를 누르면 진행 중 동작을 취소합니다.

## 파일 저장과 불러오기

기본 저장 파일은 `이름.minidraw.json`입니다. 도형의 ID, 장면 좌표, 크기, 스타일과 캔버스 배경색을 저장합니다. 열기 성공 시 파일 내용으로 장면을 교체하며, 화면에 맞추기만 적용하고 저장된 도형 좌표를 바꾸지 않습니다. 파일을 연 동작도 실행 취소로 되돌릴 수 있습니다.

```json
{
  "type": "minidraw",
  "version": 1,
  "source": "MiniDraw",
  "background": "#ffffff",
  "elements": []
}
```

추가로 `.excalidraw` 스키마 v2의 **회전하지 않은 사각형**을 읽습니다. 사용자가 제공한 `rectangle-test.excalidraw`가 이 범위에 해당합니다. 선 색상, 채우기, 굵기, 선 모양, 둥근 모서리 여부, 불투명도를 복원합니다. 손그림의 흔들림 효과는 매끈한 선으로 표시하고, 그룹·잠금·링크는 적용하지 않습니다. 단색이 아닌 채우기, 회전한 도형, 다른 종류의 도형은 오류 메시지를 보여주며 기존 작업을 유지합니다. MiniDraw 저장 파일을 Excalidraw에서 여는 호환성은 제공하지 않습니다.

최대 10MB / 2,000개 도형을 허용하고 구조·중복 ID·유한한 좌표·크기·색상을 확인한 뒤 장면을 교체합니다. 파일을 서버로 전송하지 않습니다.

## PNG 내보내기

- 장면의 모든 사각형을 포함하며, 선택 테두리와 편집 UI는 제외합니다.
- 도형들의 전체 경계에서 사방 10px 여백을 추가합니다.
- `올림(전체 경계 너비 + 20) × 배율` 및 `올림(전체 경계 높이 + 20) × 배율`로 픽셀 크기를 계산합니다.
- 배경 포함을 켜면 캔버스 배경색, 끄면 투명 배경을 사용합니다. 체크무늬는 미리보기에서 투명 영역을 구분하는 표시입니다.
- 배율을 높이면 다운로드 이미지의 픽셀 수가 증가합니다. 미리보기의 표시 크기는 일정하게 유지합니다.
- 제공된 499 × 309 사각형은 1×에서 **519 × 329**, 2×에서 **1038 × 658**, 3×에서 **1557 × 987** 픽셀입니다.
- 어느 한 변이 16,384px를 넘거나 총 3,200만 픽셀을 넘으면 내보내기를 제한합니다.

## REA 관찰과 구현 결정

| 관찰한 동작 | MiniDraw 구현 |
|---|---|
| 누른 위치와 드래그 범위에 사각형 생성 | 시작·현재 좌표의 최솟값과 차이로 미리보기 계산, 놓을 때 확정 |
| 생성 후 선택 표시와 크기 조절 핸들 | 보라색 선택 테두리와 네 모서리 핸들 |
| 이동 시 위치 변경, 크기 유지 | 드래그 시작점 대비 좌표 차이만 위치에 적용 |
| 스타일을 바꾸면 즉시 화면에 반영 | 선택 요소의 해당 속성만 변경 |
| 스타일 변경을 역순으로 취소·복원 | 실제 변경 전 장면 스냅샷을 기록, 새 수정 시 redo 비우기 |
| 파일에 위치·크기·스타일 보관 | 지원 필드를 검증한 후 한 번에 복원 |
| PNG 배경 포함 여부·배율 변경 | Canvas로 배경과 출력 픽셀 수를 독립 제어 |

순수 선택·선택 해제·화면 이동은 편집 이력에 넣지 않습니다. 연속 드래그 한 번과 불투명도 슬라이더 조절 한 번은 각각 하나의 기록입니다. 이력은 최근 100개 변경을 보관합니다. 최소 2 × 2 장면 단위보다 작은 그리기·크기 조절은 취소합니다. 이력 구조, 최소 크기, 모서리 곡률 등은 독립 구현의 설계 선택이며 원본 내부 구현이 확인되었다는 뜻은 아닙니다.


## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 편집 화면, 패널, 대화상자 |
| `styles.css` | 화면 배치, 반응형 스타일 |
| `scene.js` | 파일 검증·직렬화, 경계 계산, PNG 렌더링 |
| `app.js` | 포인터 상호작용, 스타일, 이력, 파일·다운로드 UI |
| `검증결과.md` | 실제 브라우저 검증 결과 |
